Faymee 的第一个公开版本。它是一个 macOS 菜单栏上的会议录音助手：录音、转写、区分说话人、生成纪要都在本机完成，录音和文字不离开这台 Mac。

**录音**
- 菜单栏一键录音，分片写盘，崩溃或断电后启动时自动恢复
- 自动选择麦克风（优先外接，合盖时避开内置），录音中可切换；合盖、静音、采集中断都会提示

**会后转写与说话人**
- 录音结束后自动转成文字，每句带时间，回放时高亮当前句，点一句跳到对应位置；文字可直接修改
- 自动区分说话人，可改名、合并；登记声纹后，以后的会议自动认出常一起开会的人
- 热词表：人名、产品名、术语

**纪要**
- 本机模型自动生成概要、决议、待办（负责人 + 截止时间）和未决问题，每条都能跳回原文和录音
- 五个会议模板；可编辑，可复制或导出 Markdown
- 首次使用要在设置里下载模型（约 2.5 GB），只在接通电源时自动生成

**会中**
- 会中面板显示实时字幕
- 全局快捷键 ⌃⌥M 标记重点、⌃⌥N 记一笔，纪要会重点展开标记附近的内容

**系统要求**：macOS 26 及以上，Apple Silicon（M 系列芯片）。

之后的新版本会在菜单栏面板里提示，不会弹窗打断会议；录音中不会自动重启。
