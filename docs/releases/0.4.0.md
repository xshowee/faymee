新增「纠错转写稿」：会后用纪要的大模型改正转写稿里听错的字词，改过的地方都标出来，可以撤销。

**转写纠错**
- 设置「转写」区域新增开关「纠错转写稿」，默认关。打开后每场会议转写完先纠错，再生成纪要，纪要用的是改好的文字
- 用纪要的模型，不用另外选：纪要用本机模型时只在本机运行，转写稿不上传，接通电源时才开始；纪要用在线模型时用同一个在线配置
- 本机模型只改读音相近的字词（如「对动」→「被动」）；在线模型还能补漏字、删失控复读和整句重复
- 口语词和口吃原样保留，不润色；涉及数字的修改（日期、金额等）只作为建议，由你采纳或忽略
- 改过的字加下划线，悬停看原文，可以按句撤销或「撤销全部」；转写稿标题旁的「⋯」菜单可以手动「纠错 / 重新纠错」旧会议
- 热词、已命名的说话人和会议标题会作为正确写法参考；手动改过的句子不会被纠错改动

纠错准确率还在改进，所以默认关：测试中被改的句子里，本机模型约一成改错、在线模型约 4% 改错，改错的都可以撤销。

**在线模型**
- 在线纪要和纠错的输出上限按服务商和模型放大，给会思考的模型留出余量
