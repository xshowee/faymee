新增可选的「在线模型」支持。默认仍全部在本机完成；在设置中可将「会后转写」与「纪要生成」分别切换为在线模型，使用自己的 API Key 或连接自部署服务，不经过任何中转服务器。

**在线会后转写**
- 内置阿里云百炼文件转写（支持 `qwen3-asr-flash-filetrans`、`fun-asr`、`paraformer-v2` 等，自动完成临时直传，无需自备 OSS）、OpenAI（`gpt-transcribe`）、Groq 与自定义 OpenAI 兼容入口
- 超过 24 MB 的长录音自动切段上传并拼回连续时间轴；纯文本语音接口自动通过本机时间轴对齐补全每句时间，点击句子与纪要出处照常跳播
- 自动带入全局热词表，遇到不支持热词参数的模型自动降级完成转写

**在线纪要生成**
- 原生支持 OpenAI 兼容、Anthropic（Claude）与 Google Gemini 三套协议，内置 DeepSeek、阿里云百炼、OpenAI、Anthropic、Google Gemini 五个预设及自定义入口
- 64K 大上下文窗口一次整场提取常规会议纪要；使用电池供电时也会在转写完成后自动开始生成，切离本机模型后自动释放内存

**隐私、凭据与体验**
- 实时字幕、区分说话人与声纹库自动认人继续固定在本机运行，声纹从不上传
- API Key 保存在系统钥匙串中，百炼与 OpenAI 密钥跨转写和纪要自动共用；自定义入口支持局域网/内网 `http://` 与免密访问
- 设置窗口提供「测试连接」按钮；未配齐密钥时任务保持排队并提示前往设置，请求出错明确提示原因并提供重试、绝不静默退回本机模型
- 会议详情页标明在线模型来源，复制全文、复制纪要与导出 Markdown 保持纯净无水印
