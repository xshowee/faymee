新增「系统声音」，线上会议里对方的发言也能录下来；各项本机模型改为可以自己选，新增更准的转写模型。

**系统声音**
- 菜单栏面板新增「系统声音」开关：录下本机播放的声音（腾讯会议、飞书、Zoom、浏览器里的会都行），戴耳机开线上会议也能录到对方。录音前、录音中都能切换，记住上次的设置
- 不需要虚拟声卡和“屏幕录制”权限，只需系统的“系统录音”授权；Faymee 自己回放的声音不会被录进去
- 转写、区分说话人、纪要、实时字幕都照常包含对方的声音；系统声音另外单独保存一份
- 合盖时对方的声音照常录下，转写稿标为“合盖，只录到系统声音”；系统声音不可用时只录麦克风、无声提示并自动恢复，转写稿标为“未录到系统声音”
- 会议详情标题下显示这场录音的音源

**本机模型可选**
- 设置里按用途（会后转写、实时字幕、实时字幕定稿、纪要、声纹）选择模型，每个模型标明内存、速度和适合的场景，可下载、可删除
- 会后转写新增 Fun-ASR-Nano（最准，专业词和英文最好，热词有效）、Paraformer（最稳、轻快，适合内存小的机器）、Qwen3-ASR
- 实时字幕新增 X-ASR 流式模型，比系统自带的更准；可选开启「实时字幕定稿」，每句说完后用更准的模型再识别一遍替换
- 纪要新增 Qwen3.5 4B：基本不编造截止时间，比 Qwen3 4B 更快、更省内存
- 换声纹模型后，自动用原会议录音重算声纹库
- 所选模型还没下载时，会后转写和区分说话人先排队，下载完自动开始

已在用的用户升级后保持原来的模型（会后转写 SpeechAnalyzer、纪要 Qwen3 4B），推荐在设置里改用 Fun-ASR-Nano 和 Qwen3.5 4B。
